# Inverted Search in C

## Project Overview

Inverted Search is a C project that indexes words from multiple text files using a hash table and linked lists. It stores each word along with the filenames in which it appears and its occurrence count, making word searching more efficient.

## Features

* **Create Database:** Creates an inverted index from multiple text files.
* **Display Database:** Displays indexed words and their occurrence details.
* **Search Database:** Searches for a word in the database.
* **Save Database:** Saves the database to a backup file.
* **Update Database:** Restores the database from a saved backup file.

## Technologies Used

* C Programming
* Hash Tables and Linked Lists
* Pointers and Structures
* Dynamic Memory Allocation
* File Handling
* Makefile and Command-Line Arguments

## Data Structures

* **Hash Table:** Uses 28 indexes to organize words based on their starting characters.
* **Main Node:** Stores each word, the number of files containing it, and a link to its subnodes.
* **Subnode:** Stores filenames and the number of occurrences of each word in each file.

## Key Learnings

* Implementing hash tables and linked lists.
* Managing pointers and dynamic memory allocation.
* Performing file operations and word indexing.
* Organizing multi-file C projects using Makefiles.
